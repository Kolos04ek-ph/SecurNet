# SecurNet — Инновационная система кибербезопасности

Информационная система мониторинга сетевой активности, выявления угроз и управления правилами межсетевого экранирования.

## Структура проекта
- `src/scanner.py` — модуль анализа сетевых событий и сигнатур угроз
- `src/firewall.py` — модуль управления правилами фильтрации и блокировки IP
- `tests/` — модульные и интеграционные тесты
- `docs/` — эксплуатационная документация и регламент сопровождения
- `src/alerts.py` — модуль классификации критичности и оповещения об инцидентах
